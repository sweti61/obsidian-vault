# 1. Geschützte Zeichen (für Canva essenziell)

## Geschütztes Leerzeichen (non-breaking space)
Verhindert, dass Abstände „zusammenrutschen“.
- **Windows:** `Alt + 0160`
- **Mac:** `⌥ Option + Space`

## Soft-Hyphen (weicher Trennstrich)
Für manuelle Silbentrennung in Canva.
- **Windows:** `Alt + 0173`
- **Mac:** `⌥ Option + -`

## Gedankenstrich (lang)
– typografisch korrekt (nicht der Minusstrich)
- **Windows:** `Alt + 0150` → "–"
- **Mac:** `⌥ Option + -`  

## Halbgeviertstrich (langes Gedankenstrich)
— (nur in einigen Fonts)
- **Windows:** `Alt + 0151`  
- **Mac:** `Shift + ⌥ Option + -`

# 5. Textformatierung für Canva

### ✔ Geschützte Leerzeichen  
`Alt + 0160`

### ✔ Silbentrennung  
Soft Hyphen:  
`Alt + 0173`

### ✔ Einzug simulieren  
3–6 × `Alt + 0160`

### ✔ Hängender Einzug  
Text rechts, links ein schmales Rechteck (3–4 px).

### ✔ Spaltenlayout  
Mehrere Textboxen nebeneinander, gruppieren.

### ✔ Abstand zwischen Elementen  
Shift + Pfeiltasten → schnelle Präzision.

# 10. Typografische Feinheiten

- Keine Tabs → stattdessen 2 Textboxen  
- Keine automatische Silbentrennung → Soft-Hyphen  
- Kein Blocksatz → linksbündig verwenden  
- Idealer Zeilenabstand: 1.3–1.45  
- Absatzabstand: 8–20 px  
- Geschützte Leerzeichen für saubere Abstände
