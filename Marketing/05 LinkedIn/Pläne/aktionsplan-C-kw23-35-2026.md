## 2. Silent Conversions als methodischer Anker

### 2.1 Definition

```
SILENT CONVERSIONS:

  Wirkung, die OHNE Klick entsteht. 
  Typisch fuer Beratung, Mediation, Coaching 
  im hoeheren Alter.
  
  Beispiel:
    Eine Fuehrungskraft liest Sweti's Posts 
    monatelang. Klickt nie auf einen Link. 
    Bekommt dann eine Erbstreit-Situation 
    in der Familie. Erinnert sich an Sweti. 
    Schreibt eine E-Mail oder ruft an.
  
  Diese Conversion wird nirgendwo gemessen, 
  ist aber das, worauf Beratungs-Marketing 
  hinarbeitet.
```

### 2.2 Konsequenz fuer den Aktionsplan

```
DREI METHODISCHE KONSEQUENZEN:

1. CONTENT > KLICK
   Substantielle Inhalte sind wichtiger als 
   Klick-Raten. Wenn ein Post gut ist, hat 
   er Wert, auch wenn keiner klickt.

2. WIEDERHOLTE PRAESENZ ueber Wochen
   Silent Conversions entstehen ueber 
   Monate. Konstanz wichtiger als 
   Spitzen-Reichweite.

3. PROFIL als CTA-Ziel
   Wenn jemand sich Wochen spaeter erinnert, 
   sucht er Sweti's Profil - nicht den Link 
   im damaligen Post. Profil muss daher 
   gepflegt und aktuell sein.
```

### 2.3 Was nicht mehr passiert

```
ALT (in v1):
  "Jeder Post hat einen Link zu einer 
   Marketing-Seite"
  
NEU (in v2):
  Die meisten Posts haben KEINEN Link.
  Sie funktionieren als Substanz allein.
  Profil ist das implizite CTA-Ziel.
```

## 3. Differenzierte Link-Strategie

### 3.1 70-80% linklos

```
GRUNDREGEL:

  70-80% der Posts haben KEINEN Link.
  Nur Substanz, Thought Leadership, 
  These und Klarheit.
  
  Ziel:
    Posts werden vom Algorithmus voll 
    gepusht (kein 25-35% Reichweite-
    Drop durch externen Link).
    Substanz wirkt durch sich selbst.
    Silent Conversions werden ermoeglicht.

20-30% Link-Posts (gezielt):
  Wenn ein Link gesetzt wird, dann:
  - Mit klarer Begruendung
  - Mit harten Conversion-Kriterien
  - Mit Messung (UTM-Parameter)
  - Mit Reflexion: hat sich der Link 
    gelohnt?
```

### 3.2 Wann ist ein Link wirklich noetig

```
HARTE KRITERIEN fuer einen Link:

  1. THEMA verlangt Vertiefung
     Der Post stellt eine Frage, deren 
     Antwort substantiell laenger ist als 
     der Post-Raum.

  2. ZIEL-SEITE BIETET MEHRWERT
     Klasse-B-Fachartikel, Pillarseite, 
     Lead Magnet, Substanz-Seite.
     NICHT: Service-Katalog, generische 
     Buchungsseite.

  3. CONVERSION ist messbar
     UTM-Parameter sind gesetzt.
     Sweti weiss, was er messen will.

  4. ZEITPUNKT passt
     Z.B. nach einer Anfrage in den 
     Kommentaren als Antwort-Verweis.
     Oder bei Posts mit explizitem 
     CTA-Charakter.

WENN KEIN Kriterium erfuellt: KEIN LINK.
```

### 3.3 Link-Position - keine automatische Regel

```
ALT (v1):
  "Link immer im ersten Kommentar"

NEU (v2):
  Variabel je nach Post-Charakter.
  
  Optionen:
  
  A) KEIN LINK
     Default fuer 70-80% der Posts
     
  B) LINK IM TEXT
     Bei expliziten Vertiefungs-Posts
     Akzeptiert geringe Reichweite fuer 
     gezielte Klicks
     
  C) LINK IM KOMMENTAR
     Bei spontanen Posts, wo Klick 
     sekundaer ist
     
  D) "Mehr im Profil"-Verweis
     Statt Link auf Featured-Section 
     verweisen
     Verstaerkt Profilbesuche statt 
     externer Klicks
     
  E) "Auf Anfrage" 
     Nur bei expliziter Nachfrage in 
     Kommentaren Link nachreichen

WICHTIG:
  Bei scheduled Posts ist Link im Kommentar 
  oft UNGUENSTIG, weil Sweti zum Posting-
  Zeitpunkt nicht aktiv ist und der 
  Algorithmus den fehlenden Link im Text 
  ohne Kommentar-Antwort als schwaches 
  Signal liest.
```

### 3.4 Link-Tracking

```
Wenn Link gesetzt wird:

  UTM-Parameter Pflicht:
    utm_source=linkedin
    utm_medium=organic
    utm_campaign=post_[thema]
    utm_content=[postID]
  
  Reflexions-Frage nach jedem Link-Post:
    Hat der Link Klicks gebracht?
    Haben die Klicks Conversions gebracht?
    War der Link den Reichweite-Drop wert?
  
  Konsequenz nach 4-6 Link-Posts:
    Welche Link-Typen tragen?
    Welche nicht?
    Anpassung fuer Folge-Quartal.
```

## 4. Profil-Strategie - Profil als CTA-Ziel

### 4.1 Profil-About / Featured optimieren

```
Wenn 70-80% der Posts linklos sind, wird 
das PROFIL zum impliziten CTA-Ziel.

Konsequenzen fuer Profil-Optimierung:

  ABOUT-Section:
    Hauptnarrativ klar formulieren
    Drei Verfahren benennen 
    (Konfliktberatung, Coaching, Mediation)
    Zielgruppen explizit nennen 
    (oeffentliche Verwaltung, IT-DL, 
     soziale Einrichtungen, Familien)
    Kontakt-Info am Ende 
    (E-Mail, Calendly-Link, Webseite)
  
  FEATURED-Section:
    3-5 wichtigste Cornerstone-Inhalte 
    pin'nen
    - Top Klasse-B-Fachartikel
    - Lead Magnet-Landingpage
    - beltschew.de Service-Hauptseite
    - mediator.sweti.de Themen-Hauptseite
    - Letzter Document Post
  
  HEADLINE:
    Hauptnarrativ in Kurzform
    Z.B. "Mediator + Coach + systemischer 
    Berater · Konflikte an Schnittstellen 
    von Verwaltung, IT und Familie"
```

### 4.2 Profilbesuche als Metrik

```
Statt nur Klicks auf Links zu messen, 
werden PROFILBESUCHE substantielles Signal:

  Mehrere Profilansichten pro Post sind 
  gutes Zeichen, auch ohne Link-Klick.
  
  Beispiel Post D:
    6 Profilansichten (hoechster Wert 
    aller analysierten Posts)
    0 externe Link-Klicks
    -> aber: Substanz hat zu Profil-
       Interesse gefuehrt
    -> moegliche Silent Conversions in 
       Zukunft
```

## 5. Post-Mix Strategie - mit Brueckenposts

### 5.1 Vier Post-Typen, weiterhin

```
TYP A - REFLEXIONS-POST 
        (wie Post A "Struktur als Schluessel"):
  Charakter:
    - Kontroverse These im Hook
    - 800-1500 Zeichen
    - Selbstkritische Tiefe
    - Drei-Punkt-Struktur (Pfeile)
    - Soft CTA (Orientierung, nicht 
      Verpflichtung)
  Frequenz:
    1 pro Woche
  Geeignet fuer:
    Haupt- und Nebennarrativ
  Ziel:
    Hohes Engagement, Substanz-Demonstration
  Link:
    Meist KEIN Link

TYP B - DOCUMENT POST (PDF-Carousel) - NEU:
  Charakter:
    SYSTEMISCH, nicht plakativ.
    Entscheidungsbaeume, Eskalationspfade, 
    Spannungsfelder, typische Dynamiken.
    Frage am Ende statt fertiger Loesung.
  Frequenz:
    1-2 pro Monat
  Geeignet fuer:
    Strukturelle Themen aller Narrative
  Ziel:
    Reichweite + Substanz-Demonstration
  Link:
    Meist KEIN Link 
    (Vertiefung sucht der Leser selbst 
     ueber Profil)

TYP C - PRAXISREFLEXION:
  Charakter:
    - Kuerzerer Post (400-800 Zeichen)
    - Konkrete Beobachtung aus Praxis
    - Beispielhaft, nicht doktrinal
    - Persoenlicher Ton
  Frequenz:
    1-2 pro Woche
  Geeignet fuer:
    Alle Narrative, oft Nebennarrativ
  Link:
    Meist KEIN Link

TYP D - LINKEDIN-ARTICLE:
  Charakter:
    - Langform (2000-5000 Zeichen)
    - Vertiefung eines Themas
    - Eigenes Bild als visueller Anker
    - Mit Teaser-Post + drei Fragen am Ende
  Frequenz:
    1 pro Monat (etwa KW 26, KW 30, KW 34)
  Ziel:
    SEO-Wert (Google-Indexierung), 
    Cornerstone-Substanz
  Link:
    Eventuell EIN Link zur Klasse-B-
    Vertiefung
```

### 5.2 NEU: TYP E - BRUECKENPOST

```
TYP E - BRUECKENPOST (NEU):

  Charakter:
    Verbindet berufliche und familiaere 
    Konfliktwelten explizit.
    Adressiert Leitungspersonen, die 
    beruflich mit Konflikten arbeiten 
    UND privat in aehnliche Muster geraten.
    
  Beispiele fuer Hooks:
    "Die Fuehrungskraft, die im Team 
     deeskalieren kann, scheitert beim 
     eigenen Erbstreit. Warum?"
    
    "Wer im Buero allparteilich moderiert, 
     ist zu Hause selten neutral. Das ist 
     normal - und wichtig zu wissen."
    
    "Pflege und Programmleitung gleichzeitig: 
     wenn private Sorge berufliche Klarheit 
     unterminiert."
  
  Frequenz:
    1-2 pro Monat
    Adressiert Hauptnarrativ direkt
  
  Geeignet:
    Linie 1 + Linie 2 + Linie 3 verbinden
    Anwalts-Aufmerksamkeit erzeugen
  
  Link:
    Meist KEIN Link
    Profil als CTA-Ziel
```

### 5.3 Anwalts-Fokus-Posts

```
ANWALTS-FOKUS (1-2 pro Monat):

  Charakter:
    Klar gerahmter Post oder Carousel.
    Schnittstelle "Mediation x Recht".
    Expliziter Nutzen fuer Kanzleien:
    - Weniger eskalierte Mandate
    - Bessere Vergleichsverhandlungen
    - Strukturierte aussergerichtliche 
      Loesungen
  
  Beispiel-Themen:
    "Drei Faelle, in denen Mediation der 
     Kanzlei Arbeit erleichtert"
    "Wann Mediation der Klage vorausgeht - 
     wann sie scheitert"
    "Mandanten-Entlastung durch frueh-
     zeitige Mediation - was Kanzleien 
     dabei gewinnen"
  
  Frequenz:
    1-2 pro Monat
  
  Geeignet:
    TYP A (Reflexion) oder 
    TYP B (Carousel)
  
  Link:
    Eventuell EIN Link zur Klasse-B-
    Vertiefung
```

### 5.4 Was VERMIEDEN wird

```
✗ Service-Katalog-Posts (wie Post B 
  "Drei Verfahren") - vermieden
  - Vollstaendige Service-Definitionen
  - Mehrere Links nebeneinander
  - Verkaufender Ton

✗ Vollstaendige Bilder (wie Post C) - 
  vermieden
  - Bilder, die alle Information enthalten
  - Tabellen mit Empfehlungen
  - Bilder, die den Klick ersetzen

✗ "5 Tipps"-Carousels - vermieden
  - Listicle-Charakter
  - Vereinfachung statt Strukturierung
  - Coaching-Kitsch-Risiko

✗ Generische Werbe-Posts
  - "Buchen Sie hier!"
  - Pathosbeladene Eigenanpreisung
  - Keine Substanz, nur CTA

✗ Doc-Posts ohne systemische Tiefe
  - Plakative Vereinfachung
  - Oberflaechliche Aufzaehlungen
```

## 8. Erste-Stunde-Engagement (nach Posting)

### 8.1 Methodischer Anker

```
LinkedIn-Algorithmus operiert als Real-Time 
Semantic Ranking System.
Die ersten 60-90 Minuten nach Posting 
entscheiden ueber Reichweite.

Wenn fruehe Reaktionen kommen, pusht 
LinkedIn den Post weiter.
Wenn nicht, drosselt LinkedIn ihn dauerhaft.
```

### 8.2 Routine nach jedem Posting

```
0-15 Min nach Posting:
  - LinkedIn offen lassen
  - Erste Reaktionen pruefen
  - Auf Likes vorerst nicht reagieren

15-30 Min:
  - Erste Kommentare ggf. lesen
  - Erste substantielle Antworten

30-60 Min:
  - Konsequent jeden Kommentar 
    inhaltlich beantworten
  - Eigene Aussagen vertiefen
  - Fragen stellen
  - Diskussion weiterfuehren

60-90 Min:
  - Pruefen: hat sich Diskussion entwickelt?
  - Falls ja: weiterfuehren
  - Falls nein: nicht erzwingen

Nach 90 Min:
  - LinkedIn schliessen
  - Bei spaeteren Kommentaren tageszeit-
    abhaengig antworten 
    (mind. 1x pro Tag)
```

### 8.3 Methodische Auswirkung

```
Aktuelle Posting-Zeiten:
  Di 8:30 (12-Wochen-Themenplan)
  Mo morgens 
  ...

Konsequenz: 
  Sweti sollte in diesen Zeitfenstern 
  verfuegbar sein.
  
  NICHT posten, wenn nicht 60-90 Min 
  verfuegbar.
  
  Eventuell scheduled Posts auf Zeiten 
  legen, wo Sweti sicher verfuegbar ist.
```
