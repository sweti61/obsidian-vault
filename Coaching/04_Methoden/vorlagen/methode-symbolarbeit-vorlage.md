# 🧭 Symbolarbeit (Vorlage)

> Ziel: Innere Themen über Symbole oder Bilder sichtbar und besprechbar machen

## 🎴 Symbolauswahl (optional aus Gegenständen, Karten, Bildern)

| Symbol / Objekt        | Was drückt es für dich aus?                   |
|------------------------|-----------------------------------------------|
|                        |                                               |
|                        |                                               |

## 🧠 Bedeutung & Wirkung

- Warum hast du dieses Symbol gewählt?
- Was erinnert es dich?
- Welche Aspekte deines Themas zeigt es?
- Was wird dadurch klarer?

## 🔄 Transfer

- Welche Idee entsteht durch dieses Symbol?
- Wie könntest du es im Alltag bewusst einsetzen?
- Welche neue Sichtweise ergibt sich für dich?
