### 3.1 Schema Markup (Strukturierte Daten)

Schema Markup hilft Google, Ihre Seite als seriöses lokales Unternehmen einzustufen und Rich Snippets anzuzeigen. Fügen Sie folgenden JSON-LD-Code im `<head>` Ihrer Startseite ein:

```json
{
  "@context": "https://schema.org",
  "@type": "LocalBusiness",
  "name": "Mediator-Sweti – Sweti Beltschew",
  "url": "https://mediator.sweti.de",
  "telephone": "+49-[Ihre Telefonnummer]",
  "address": {
    "@type": "PostalAddress",
    "streetAddress": "[Straße]",
    "addressLocality": "Dresden",
    "addressRegion": "Sachsen",
    "postalCode": "[PLZ]",
    "addressCountry": "DE"
  },
  "geo": {
    "@type": "GeoCoordinates",
    "latitude": 51.0504,
    "longitude": 13.7373
  },
  "description": "Systemischer Mediator in Dresden. Konfliktlösung für Familien, Unternehmen, Senioren und IT-Projekte.",
  "serviceArea": {
    "@type": "GeoCircle",
    "geoMidpoint": {
      "@type": "GeoCoordinates",
      "latitude": 51.0504,
      "longitude": 13.7373
    },
    "geoRadius": "100000"
  },
  "priceRange": "$$",
  "openingHoursSpecification": [
    {
      "@type": "OpeningHoursSpecification",
      "dayOfWeek": ["Monday","Tuesday","Wednesday","Thursday","Friday"],
      "opens": "09:00",
      "closes": "18:00"
    }
  ]
}
```

> **Validierung:** Testen Sie den Code unter [search.google.com/test/rich-results](https://search.google.com/test/rich-results)

## 4. Google Search Console (GSC) – Einrichtung & Überwachung

Die Google Search Console ist das wichtigste kostenlose Tool zur Überwachung Ihrer Google-Sichtbarkeit. Sie zeigt, bei welchen Suchbegriffen Sie gefunden werden, wie viele Klicks Sie erhalten und wo Probleme bestehen.

---

### 4.1 Website in GSC verifizieren

1. Gehen Sie zu [search.google.com/search-console](https://search.google.com/search-console) und melden Sie sich an
2. Klicken Sie auf "Property hinzufügen"
3. Wählen Sie "Domain" und geben Sie `mediator.sweti.de` ein
4. Verifizierung per DNS-Eintrag: TXT-Eintrag kopieren und in den DNS-Einstellungen einfügen
5. Alternativ: HTML-Tag-Methode – Meta-Tag im `<head>` der Website einfügen
6. Klicken Sie auf "Bestätigen" – Verifizierung dauert 24–72 Stunden

> **Hinweis:** Bei Hugo CMS können Sie den Verifizierungs-Meta-Tag direkt in die `head.html`-Partial-Datei einfügen.

---

### 4.2 Sitemap einreichen

1. Prüfen Sie, ob eine Sitemap existiert: `mediator.sweti.de/sitemap.xml`
2. In GSC: Linkes Menü → Indexierung → Sitemaps
3. Geben Sie `sitemap.xml` ein und klicken Sie "Senden"
4. Status sollte nach 1–2 Tagen auf "Erfolg" wechseln

> **Hinweis:** Hugo generiert automatisch eine `sitemap.xml` – prüfen Sie, dass alle wichtigen Seiten enthalten sind.

---

### 4.3 GSC-Berichte: Was Sie wöchentlich prüfen sollten

#### Leistungsbericht (Search Analytics)

| Kennzahl | Was sie bedeutet | Zielwert |
|---|---|---|
| Klicks | Besucher, die über Google kommen | Monatlich steigend |
| Impressionen | Wie oft die Seite in Suchergebnissen erscheint | Monatlich steigend |
| CTR (Click-Through-Rate) | Anteil der Suchanfragen, die zu Klicks führen | > 3 % |
| Durchschnittliche Position | Ranking in den Suchergebnissen | Ziel: < 10 (erste Seite) |

**Wichtige Filter:**
- Nach "Abfragen" filtern → welche Keywords zeigen Klicks?
- Nach "Seiten" filtern → welche Unterseiten performen am besten?

#### Indexierungsberichte

- **Abdeckung** → prüfen, ob alle Seiten indexiert sind
- **Fehler beheben:** 404-Fehler, Soft 404, Weiterleitungsfehler sofort korrigieren
- **"Ausgeschlossen" prüfen:** wichtige Seiten dürfen nicht aus dem Index ausgeschlossen sein

#### Core Web Vitals

| Metrik | Bedeutung | Zielwert |
|---|---|---|
| LCP (Largest Contentful Paint) | Ladezeit des größten Seitenelements | < 2,5 Sekunden |
| CLS (Cumulative Layout Shift) | Unerwartete Layoutverschiebungen | < 0,1 |
| INP (Interaction to Next Paint) | Reaktionszeit auf Nutzerinteraktionen | < 200 ms |

> **Hinweis:** Core Web Vitals sind erst aussagekräftig, wenn genug Traffic vorhanden ist (ca. 1.000+ Klicks/Monat).

#### Wichtige GSC-Aktionen für die ersten 3 Monate

1. Nach jeder neuen Seite oder Blog-Artikel: URL in GSC zur Indexierung einreichen (URL-Inspektion → Indexierung beantragen)
2. **Monatlich:** Top-10-Keywords exportieren und Positionen in einer Tabelle tracken
3. **Monatlich:** Prüfen, ob neue Fehler aufgetreten sind
4. **Vierteljährlich:** Welche neuen Keywords erscheinen? → Daraus Blog-Ideen ableiten

## 5. Google Tag Manager (GTM) – Einrichtung & Konfiguration

Der Google Tag Manager ist ein Container-System für alle Tracking-Codes. Statt jeden Code direkt in die Website einzufügen, verwalten Sie alle Tags zentral im GTM.

---

### 5.1 GTM-Container erstellen & einbinden

1. Gehen Sie zu [tagmanager.google.com](https://tagmanager.google.com) und melden Sie sich an
2. Klicken Sie auf "Konto erstellen" → Kontoname: Sweti Beltschew
3. Container-Name: `mediator.sweti.de` | Zielplattform: Web
4. Sie erhalten zwei Code-Snippets:
   - **Script-Tag** → in den `<head>`-Bereich der Website (so weit oben wie möglich)
   - **noscript-Tag** → direkt nach dem öffnenden `<body>`-Tag
5. Bei Hugo CMS: Code in die Partial-Dateien `head.html` bzw. `body.html` einfügen
6. Verifizieren: GTM-Vorschaumodus aktivieren → mediator.sweti.de aufrufen → GTM-Symbol muss erscheinen

---

### 5.2 Wichtige Tags in GTM einrichten

#### Tag 1: Google Analytics 4 (GA4) – Seitenaufrufe

1. Tags → Neu → Tag-Konfiguration: **Google Analytics: GA4-Konfiguration**
2. Mess-ID eingeben (Format: `G-XXXXXXXXXX`) – kommt aus GA4
3. Trigger: **All Pages** (Alle Seiten)
4. Tag benennen: `GA4 – Grundkonfiguration`
5. Speichern

#### Tag 2: Kontaktformular-Tracking (Conversion)

1. Trigger erstellen: Typ "Formularübermittlung" oder "Klick" auf den Kontakt-Button
2. Tag erstellen: GA4 Event – Ereignisname: `contact_form_submit`
3. Parameter: `event_category = Kontakt`, `event_label = Formular`
4. Trigger: Formular-Übermittlung auf Kontaktseite

> **Hinweis:** Jede Kontaktanfrage ist eine Conversion. Dieses Tracking zeigt Ihnen, welche Seiten Klientenanfragen generieren.

#### Tag 3: Telefon-Klick-Tracking

1. Trigger: Klick-URL enthält `tel:` (Telefonnummer-Klick auf Mobilgeräten)
2. Tag: GA4 Event – Ereignisname: `phone_click`
3. So sehen Sie, wie viele Besucher auf Ihre Telefonnummer klicken

---

### 5.3 GTM veröffentlichen

1. Alle Tags und Trigger erstellt? → Rechts oben: "Senden"
2. Versionsbeschreibung eingeben, z.B.: `GA4 Basis + Kontaktformular-Tracking`
3. Klicken Sie "Veröffentlichen"
4. Prüfung: GA4 Echtzeit-Bericht öffnen → eigene Website besuchen → Besucher sollte erscheinen

## 6. Google Analytics 4 (GA4) – Einrichtung & Berichte

GA4 ist das aktuelle Webanalyse-Tool von Google. Es zeigt, wer Ihre Website besucht, woher die Besucher kommen und was sie auf der Seite tun.

---

### 6.1 GA4-Property erstellen

1. Gehen Sie zu [analytics.google.com](https://analytics.google.com)
2. Klicken Sie auf das Zahnrad (Verwaltung) → "Property erstellen"
3. Property-Name: `Mediator Sweti` | Zeitzone: Deutschland | Währung: Euro
4. Klicken Sie auf "Weiter" → Unternehmensgröße: Klein | Branche: Gesundheit / Beratung
5. "Datenstream hinzufügen" → Web → `mediator.sweti.de` eingeben
6. Mess-ID (`G-XXXXXXXXXX`) kopieren – für GTM benötigt
7. Erweiterte Messung aktivieren: Scrollen, ausgehende Klicks, Suche, Videos

---

### 6.2 Wichtige GA4-Berichte für Ihren Alltag

#### Echtzeit-Bericht

- Menü links: Berichte → Echtzeit
- Zeigt aktuelle Besucher auf der Seite
- Zum Testen neuer Konfigurationen ideal

#### Nutzergewinnungsbericht

- Berichte → Gewinnung → Nutzergewinnung
- Zeigt: Woher kommen Ihre Besucher? (Google, direkt, Social Media)
- Ziel: Der Kanal "Organisch" (Google-Suche) soll wachsen

#### Engagement-Bericht

| Kennzahl | Bedeutung | Zielwert |
|---|---|---|
| Durchschnittliche Sitzungsdauer | Wie lange Besucher auf der Seite bleiben | > 2 Minuten |
| Seiten pro Sitzung | Wie viele Seiten pro Besuch aufgerufen werden | > 2 Seiten |
| Absprungrate | Anteil der Besucher, die sofort abspringen | < 60 % |

#### Conversion-Tracking

- Berichte → Engagement → Conversions
- Hier erscheinen Kontaktformular-Einsendungen und Telefon-Klicks
- Monatliches Ziel definieren: z.B. **5 Klientenanfragen/Monat**

---

### 6.3 Benutzerdefiniertes SEO-Dashboard einrichten

1. Gehen Sie zu "Erkunden" (linkes Menü) → "Leer" → neuen Bericht erstellen
2. Dimensionen hinzufügen: Seitenname, Kanal, Gerätekategorie
3. Messwerte hinzufügen: Sitzungen, Engagierte Sitzungen, Conversions, Ereignisanzahl
4. Filter: Nur organischer Traffic (Kanal enthält "Organic")
5. Speichern als: `SEO-Übersicht`

> **Hinweis:** Dieser Bericht zeigt Ihnen jede Woche in 2 Minuten, ob Ihre SEO-Maßnahmen wirken.

---

### 6.4 GA4 mit GSC verknüpfen

1. GA4 → Verwaltung → Property-Einstellungen → **Search Console-Verknüpfungen**
2. Klicken Sie "Verknüpfen" → Ihre GSC-Property auswählen
3. "Bestätigen" klicken
4. Jetzt erscheint in GA4 ein neuer Bericht: Berichte → Gewinnung → Search Console
5. Dieser zeigt: welche Google-Suchanfragen zu Ihren Websitebesuchen führen – direkt in GA4

## 7. Priorisierter Aktionsplan (90 Tage)

Dieser Plan strukturiert alle Maßnahmen nach zeitlicher Priorität. Beginnen Sie mit Phase 1, bevor Sie Phase 2 starten.

---

### Phase 1: Sofort (Woche 1–2)

**Technische Grundlage und Tracking-Setup – Basis für alle weiteren Maßnahmen**

1. GSC verifizieren und Sitemap einreichen
2. GTM-Container einrichten und auf Website einbinden
3. GA4-Property erstellen und mit GTM verbinden
4. GA4 mit GSC verknüpfen
5. Kontaktformular-Tracking einrichten (erste Conversion)
6. Schema Markup (LocalBusiness JSON-LD) auf Startseite einbinden
7. Grammatikfehler korrigieren: "im Dresden" → "in Dresden"
8. Google Business Profil anlegen oder vervollständigen

---

### Phase 2: Kurzfristig (Woche 3–6)

**Onpage-SEO und Keyword-Optimierung**

1. Title Tags aller Seiten überarbeiten (Keyword + Ort + Marke)
2. Meta-Descriptions für alle Seiten individuell schreiben
3. H1-Tags auf jeder Seite: genau 1 H1, primäres Keyword enthalten
4. Startseite: Keyword "Mediator Dresden" prominent platzieren
5. 5 neue Dienstleistungs-Landingpages erstellen (Familienmediation, Wirtschaftsmediation, IT-Mediation, Elder Mediation, Scheidungsmediation)
6. Bewertungsanfragen an zufriedene Klienten senden (Google + Verzeichnisse)

---

### Phase 3: Mittelfristig (Woche 7–12)

**Inhalte, Backlinks und kontinuierliche Optimierung**

1. 2 Blog-Artikel pro Monat veröffentlichen (Long-Tail-Keywords aus der Keyword-Matrix)
2. Eintrag bei mediator-finden.de, heymediation.de, mediatorgesucht.de
3. GA4 und GSC wöchentlich auswerten: Welche Keywords steigen?
4. A/B-Test: 2 verschiedene Call-to-Action-Texte auf Startseite testen
5. Interne Verlinkung überprüfen: Jede Seite sollte min. 2 interne Links haben
6. Pagespeed mit PageSpeed Insights prüfen und Bilder komprimieren

---
