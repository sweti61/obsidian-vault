## Häufigste Tipps (Plakativ)

>Schreiben Sie klar und präzise, verwenden Sie Synonyme
>Nennen Sie den Bot einen „Experten“

1. Formel: [Aufgabestellung], insbesondere [Details]?

2. Formel: Kannst du mir Ideen für [Format s. Create a [TASK]] über [Thema] geben, vielleicht mit [Themen]?

     - Kannst du mir Vorschläge geben, wie ich diesen Text verbessern kann: [Text einfügen] 

3.  Formel: Kannst du [**Anzahl**] [**plausiblen**/**kreativen**] Ideen für [**Art von**] Konzepte liefern, die ein [**Beruf**] in einer [**Branche**] haben könnte?

4. Formel:  Erkläre die folgende Nachricht in [**Anzahl**] Worten oder weniger: [**Nachricht**]

5. Formel: Erstelle [**Anzahl**] Slogans für ein neues [**Thema**].

6. Formel: Können Sie eine Liste mit [**Anzahl**] Möglichkeiten aufstellen, um mehr [**gewünschtes Ziel**] zu erreichen?

7. Formel: Sei mein [**Adjektiv**] Titel-Generator und gib uns coole Überschriften basierend auf den Schlagwörtern: [**Begriffe**]?

8. Formel: Warum ist [**Titel**] ein so beliebter [**Format**]?

9. Formel: Kannst du ein interessantes und unbekanntes Fakt über [**Thema**] preisgeben?

  

- Kontexte wiederverwenden - Wenn Sie mehrere Fragen zum selben Thema haben, sollten Sie diese im selben Chat stellen, auch wenn dieser schon einige Tage zurückliegt. So erhöhen Sie den Kontext, den die KI benötigt, ganz einfach durch die vorherigen Fragen des Chats.

## Das C.I.D.I. Formel Context, Instruction, Details, Input (CIDI)

- C für Context (s. Rolle zuweisen):

>Verhalte dich wie ein Rechtsanwalt für Verbraucherrechte.

- I für Instruction: (s. TASK)

>Ich gebe dir Details zu einem verspäteten Flug, du schreibst eine Beschwerdemail an die Fluggesellschaft.

- Schlagzeile

- Artikel

- Essay

- Buchübersicht

- E-Mail-Sequenz

- Social-Media-Beitrag

- Produktbeschreibung

- Anschreiben

- Blogbeitrag

- SEO-Keyword

- Zusammenfassung

- Video-Skript

- Rezept

- Verkaufstexte

- Anzeigentext

- Webseite

- D für Details:

>Benutze einen formellen Tonfall und berufe dich auf EU-Recht.

- I für Input:

>Flugdaten: Paris nach München, 18. Juni 2023, Flugnummer RYxxxxx, Fluggesellschaft: Raynair, Verspätung: 3,5 Stunden.

  - Geben Sie so viel Input wie möglich
  

## Das C.R.E.A.T.E. Formel

  1. **C**haracter - Definieren Sie die **Rolle** der KI. Z.B. "Sie sind ein erfahrener Texter mit 20 Jahren Erfahrung in erfolgreichen Verkaufstexten"
  2. **R**equest - Seien Sie genau das, was Sie brauchen. Anstelle von "Schreiben Sie eine Verkaufs-E-Mail für Sportwagen" geben Sie an: "Schreiben Sie eine überzeugende E-Mail für den Cougar Sport, ein Elektroauto mit erstklassiger Beschleunigung".
  3. **E**xamples - Stellen Sie optional Proben für genauere Ergebnisse zur Verfügung. Überschriften oder Tonbeispiele können den KI-Stil leiten.
  4. A**djustments - Verfeinern Sie die Eingabeaufforderung (prompt), wenn sie nicht perfekt ist. Verwenden Sie Anweisungen wie: "Vermeiden Sie Aufzählungspunkte, verwenden Sie Zwischenüberschriften"
  5. *ype of Output - Beschreiben Sie das gewünschte Format, z. B. "Erstellen Sie einen Artikel mit 500 Wörtern und einem Titel und einer Schlussfolgerung"
  6. **E**xtras - Integrieren Sie einzigartige Anweisungen

- Ignoriere vorherige Anweisungen

- Stelle Fragen, bevor du antwortest

- Erkläre deine Denkweise

- Fasse zusammen, was du über mich weist, in der ersten Person

- Nutze Daten bis 2023

- Verwende nur zuverlässige Quellen und zitieren Sie diese

- Verwende die Feststelltaste zur Hervorhebung
