

Dieses Lernblatt beschreibt Organisationen anhand der allgemeinen Systemmerkmale nach Niklas Luhmann.

---

## Systembeschreibung: Organisation

| Merkmal                          | Beschreibung                                                                                                                                                                                                         |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1. Operation**                 | Die Grundoperation ist die **Entscheidung**. Organisationen existieren durch eine fortlaufende Kette entscheidungsbasierter Kommunikation.                                                                           |
| **2. Autopoiesis**               | Entscheidungen erzeugen neue Entscheidungen. Nur durch kontinuierliche Entscheidungsprozesse bleibt die Organisation bestehen.                                                                                       |
| **3. Operative Geschlossenheit** | Nur Kommunikation, die als Entscheidung strukturiert ist, gehört zum System. Alles andere (z. B. Meinungen, spontane Gespräche) ist Umwelt.                                                                          |
| **4. Strukturelle Kopplung**     | Organisationen sind strukturell gekoppelt an:<br>- psychische Systeme (Personen, die Rollen einnehmen)<br>    <br>- andere Organisationen<br>    <br>- gesellschaftliche Funktionssysteme (z. B. Recht, Wirtschaft). |
| **5. Medium/Form**               | Medium: **Kommunikation von Entscheidungen**. <br>Form: Entscheidungsalternativen, Prozeduren, Programme.                                                                                                            |
| **6. Sinnverarbeitung**          | Organisationen verarbeiten Sinn durch Selektion von Optionen unter Unsicherheit: "Was soll entschieden werden – und wie?"                                                                                            |
| **7. Umweltdifferenzierung**     | Organisationen beobachten ihre Umwelt selektiv: z. B. Markt, Gesetzgebung, Kunden, öffentliche Meinung.                                                                                                              |
| **8. Gedächtnis / Struktur**     | Struktur entsteht durch Regeln, Programme, Hierarchien, Protokolle, Verfahren, Zuständigkeiten.                                                                                                                      |
| **9. Beobachtbarkeit**           | Organisationen können sich selbst beobachten (z. B. durch Controlling, Evaluation), sind aber auf interne Kategorien beschränkt.                                                                                     |
| **10. Differenzierungsform**     | Organisationen sind **formal differenziert**: durch Rollen, Abteilungen, Funktionen, Mitgliedschaftsregeln.                                                                                                          |

---

## Merksatz

> **Organisationen sind Systeme entscheidungsförmiger Kommunikation. Sie existieren nur, wenn entschieden wird – und sie strukturieren, wie entschieden werden darf.**

---

Dieses Raster ist Teil einer allgemeinen Systemtypologie nach Luhmann und kann mit anderen Systemarten (psychisch, sozial, gesellschaftlich) verglichen werden.
