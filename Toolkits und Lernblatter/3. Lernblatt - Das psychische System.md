# Lernblatt: Das psychische System (nach Luhmanns Systematik)

Dieses Lernblatt beschreibt das psychische System anhand der allgemeinen Systemmerkmale nach Niklas Luhmann.

---

## Systembeschreibung: Psychisches System

| Merkmal                          | Beschreibung                                                                                                                                 |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| **1. Operation**                 | Die Grundoperation ist der **Gedanke**. Jeder neue Gedanke entsteht im Anschluss an vorherige Gedanken.                                      |
| **2. Autopoiesis**               | Das System reproduziert sich selbst: Gedanken erzeugen Gedanken. Kein Gedanke kommt direkt von außen.                                        |
| **3. Operative Geschlossenheit** | Es verarbeitet ausschließlich eigene Operationen. Umweltreize können es nur **irritieren**, nicht direkt beeinflussen.                       |
| **4. Strukturelle Kopplung**     | Gekoppelt an: - den biologischen Körper  <br>- soziale Systeme (Kommunikation)  <br>- andere psychische Systeme (z. B. durch Interaktion).   |
| **5. Medium/Form**               | Das Medium ist **Sinn**, realisiert in der Form: **Aktualität vs. Möglichkeit**. Jeder Gedanke steht im Horizont anderer möglicher Gedanken  |
| **6. Sinnverarbeitung**          | Das System verarbeitet Sinn durch Auswahl und Verknüpfung von Bedeutungen.                                                                   |
| **7. Umweltdifferenzierung**     | Es unterscheidet:  <br>- Innen (eigene Gedanken) vs. Außen (Reize, Sprache, Personen)  <br>- Selbstbezug vs. Fremdbezug  <br>- Ich vs. Welt. |
| **8. Gedächtnis / Struktur**     | Struktur entsteht durch wiederholte Gedankenmuster, Routinen und semantische Konzepte.                                                       |
| **9. Beobachtbarkeit**           | Es kann sich **selbst beobachten** (Selbstreflexion), aber nur aus eigener Perspektive.                                                      |
| **10. Differenzierungsform**     | Dasi ist **individuell** ausgebildet, nicht segmentiert oder funktional differenziert.                                                       |
|                                  |                                                                                                                                              |
|                                  |                                                                                                                                              |
|                                  |                                                                                                                                              |

---

## Merksatz

> **Psychische Systeme sind autopoietische Sinnsysteme, die durch Gedanken operieren, sich selbst beobachten und von ihrer Umwelt nur irritiert werden können.**

---

Dieses Raster kann auch zur Beschreibung anderer Systemtypen (soziale Systeme, biologische Systeme etc.) verwendet werden.
